# Magatartási szabályok

A projekt tárgyszerű, bizonyítékokra épülő szakmai együttműködést vár el.

Elvárt:

- a személy helyett az állítás és a bizonyíték értékelése;
- források, bizonytalanságok és érdekütközések nyílt jelzése;
- tiszteletteljes, közérthető kommunikáció;
- a hibák javítása és a reprodukálhatóság támogatása.

Nem elfogadható a zaklatás, személyeskedés, megtévesztés, manipulált adat, spam vagy bizalmas információ engedély nélküli közzététele. Probléma esetén repository Issue helyett privát GitHub-kapcsolatfelvétel vagy biztonsági bejelentés használható.
