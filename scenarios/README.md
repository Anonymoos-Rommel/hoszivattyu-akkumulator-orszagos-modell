# Forgatókönyvek

Minden scenario verziózott bemeneti csomag. Kötelezően tartalmazza:

- scenario azonosító és leírás;
- modellverzió vagy commit;
- minden eltérített input változóazonosítója;
- futtatási időpont;
- validációs eredmény;
- kimeneti fájlok és lenyomatok.

Az eredmények nem írhatók vissza kanonikus alapértékként külön forrás- vagy döntési rekord nélkül.
