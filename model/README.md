# Számítási motor

Ebben a könyvtárban készül a későbbi determinisztikus számítási motor.

Követelmények:

- bemenet kizárólag a kanonikus változó-regiszteren keresztül;
- explicit mértékegységek;
- verziózott képletek;
- reprodukálható scenario-futtatás;
- baseline és inkrementális programhatás elkülönítése;
- automatikus duplaelszámolás-ellenőrzés;
- generált kimenetek kézi szerkesztésének tiltása.
