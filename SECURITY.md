# Biztonsági szabályzat

Biztonsági problémát, kiszivárgott titkot, személyes adatot vagy veszélyes workflow-jogosultságot ne nyilvános Issue-ban jelents.

Használd a GitHub repository **Security advisories / Report a vulnerability** funkcióját. Ha ez nem érhető el, a repository tulajdonosával privát GitHub-csatornán vedd fel a kapcsolatot.

A GitHub Actions workflow-k alapértelmezett jogosultsága csak olvasás. Külső Pull Request nem kaphat repository-secretet vagy írható tokent.
